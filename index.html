1. Set up items
Go to Items tab → find your item (e.g. 60x60 Tiles) → click Set Dual → enter Primary Unit (Box), Secondary Unit (Metre), Ratio (1.5 = 1 Box equals 1.5 Metres), and prices.
2. Convert quantities
Go to Calculator → select item → type in either unit. The other auto-calculates.
3. Fill into invoice
Click any quantity field in the Manager.io invoice form, then click Fill as Box or Fill as Metre. The value is copied to clipboard — paste it in.
4. Invoice view
Open Invoice tab → click Load → see all line items with dual unit quantities side by side.
